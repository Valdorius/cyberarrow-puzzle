# CyberArrow: Circuit Escape ⚡

Тактильная логическая кибер-головоломка для Android и Web с поддержкой **Playgama Bridge SDK**.

## 🎮 Особенности
- **Core-геймплей:** тактильная расчистка заблокированных шин данных и маршрутов стрелок.
- **Гарантия проходимости:** математический алгоритм обратной генерации (*Reverse Step Generation*) — никаких случайных тупиков.
- **Особые чипы:** Квантовые Ротаторы (⚡) — поворачивают соседние стрелки на 90° при вылете.
- **Android-first:** Портретный режим для игры одной рукой, тактильная вибрация (Haptic Feedback), чистый синтезированный звук через Web Audio API.
- **Playgama Bridge SDK:**
  - Автоматическая пауза и отключение звука при показе рекламы.
  - Interstitial-реклама в естественных паузах между уровнями.
  - Rewarded-видео за дополнительные подсказки.
  - Облачная синхронизация прогресса через `bridge.storage`.

## 🚀 Запуск через GitHub Pages
Проект готов для публикации на **GitHub Pages**:
1. Перейдите в **Settings** репозитория на GitHub -> **Pages**.
2. В секции **Build and deployment** выберите Source: `Deploy from a branch`.
3. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Игра будет доступна по ссылке: `https://<ваш_логин>.github.io/<репозиторий>/`.

## 🛠 Локальный запуск
```bash
python -m http.server 8080 --bind 127.0.0.1
```
Откройте в браузере: `http://127.0.0.1:8080`
